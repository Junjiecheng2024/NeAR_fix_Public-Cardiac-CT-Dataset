# Phase 2: Morphological Processing & Cleaning

## Overview
In Phase 2, we process the raw probability maps generated by the NeAR models in Phase 1. The goal is to convert these implicit representations into explicit binary masks and perform topological cleaning to remove noise and artifacts.

## Methodology
We apply a tiered morphological strategy based on the anatomical characteristics of each class:

1.  **Large Organs (LV, RV, LA, RA, Myocardium)**:
    *   **Closing**: Radius = 3 voxels. Fills internal holes and smooths boundaries.
    *   **CC Filtering**: Keep only the **largest single** connected component (CC=1). Removes floating artifacts.

2.  **Tubular Structures (Coronary Arteries)**:
    *   **Closing**: Radius = 2 voxels. Connects small gaps while preserving vessel width.
    *   **CC Filtering**: Keep the **largest 2** components (corresponding to Left and Right Coronary Arteries).

3.  **Multi-Source Structures (Pulmonary Veins)**:
    *   **CC Filtering**: Keep the **largest 4** components (corresponding to the 4 standard pulmonary veins).

## Usage

### Run Full Phase 2 Pipeline
The `run_phase2.sh` script automates the inference and morphological processing for all classes.

```bash
./run_phase2.sh
```

### Scripts
*   `perform_morphology_v2.py`: The core script that applies morphological operations and CC filtering.
*   `calculate_phase2_cc.py`: Verifies the connected components of the processed masks to ensure cleaning effectiveness.
