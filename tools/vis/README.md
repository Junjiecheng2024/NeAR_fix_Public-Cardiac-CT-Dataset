# Visualization Tools

This directory contains visualization helpers:

- `visualize_tier2_sample.py`: inspect Tier2 sample contents
- `phase1_visualize_sample.py`: inspect Phase1 sample-level inputs and outputs
- `phase1_visualize_3d.py`: render Phase1 single-class 3D results
- `phase3_visualize_3d.py`: render Phase3 comparison views in 3D
- `phase3_visualize_phase3.py`: generate Phase3 case-level comparison outputs
- `export_nifti.py`: export arrays to NIfTI files for inspection

These scripts do not affect the main training or repair pipeline.
